# 问道互联（HowToGo Connect）

让服务器上所有玩家共用同一套路网 —— 你画的路，别人也能走。

## 需要什么

| | 版本 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.259 或更高 |
| 问道 HowToGo | **0.2.2 或更高**（必须） |

客户端和服务端都要装。问道在服务端不需要装。

## 怎么用

**玩家** —— 进服会弹窗，点「接收」。之后按 `K` 打开问道，看到的就是服务器的路网。

**服主** —— 把路网文件放到 `config/htg_connect/server_network.json`，改完 5 秒内自动同步给所有在线玩家，不用重启。

**房主开房** —— 什么都不用做。房主画什么，房间里的人就同步什么。
