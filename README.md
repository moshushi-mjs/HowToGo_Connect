# 问道互联（HowToGo Connect）

让同一个服务器上的玩家，用同一张地图。

问道的路网和地点默认只存在每个玩家自己的电脑里。同一个服务器上，你标了"我家"，
朋友打开问道，列表里什么都没有。装上这个之后，服务器统一发一套路网给所有人：

- 大家看到的路、地点完全一样
- 服务器改了路网，所有人 5 秒内自动更新
- 玩家自己改的路会被服务器的覆盖掉

---

## 需要什么

| | 版本 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.259 或更高 |
| 问道 HowToGo | 0.2.3 或更高 |

装在哪：

| | |
|---|---|
| 客户端 | 必须装 |
| 服务端 | 必须装（用来发路网） |
| 问道 | 服务端不用装 |

装法：把 jar 丢进 `mods` 文件夹。

> 启动时报"问道版本不满足"，说明问道太旧，换成 0.2.3 或更高。

---

## 玩家

进服会看到一个「问道互联」窗口，里面列出服务器有路网的每一个维度，以及各自的文件大小。

窗口不能直接关掉，只能选「接收」或「拒绝」。

点「接收」代表你同意自动下载服务器上的路网文件
之后按 `K` 打开问道，看到的就是服务器的路网。

任何时候都可以按 `H` 打开「问道互联」面板（也可以敲 `/htg_connect info`），
里面列着服务器每个维度的大小和你的接收状态：已接收、有更新、未接收。
面板上能直接点「接收」，也能点「刷新」重新刷一遍路网大小。

## 服主：独立服务端

### 准备路网

在自己客户端里画好路，找到：

```
<客户端目录>\config\howtogo\<世界目录>\minecraft_overworld.json
```

复制到服务器：

```
<服务端目录>\config\htg_connect\server_network.json
```

`config\htg_connect\` 不存在就自己建一个。

### 存放方式

```
config\htg_connect\
    dimensions.json                              维度 id 对应哪个文件
    server_network.json                          主世界
    server_network.minecraft_the_nether.json     下界
    server_network.minecraft_the_end.json        末地
    server_network.<维度>.json                   其他维度
    *.bak                                        每个维度各自一份备份
```

文件名里的维度，是把维度 id 里除了字母、数字和 `.` `_` `-` 以外的字符换成下划线得到的。
`dimensions.json` 记的是"哪个维度用哪个文件"，可以手动改。

### 生效

服务器每 5 秒检查一次这些文件。改了 → 自动重新读 → 推给在线玩家。

> 不用重启服务器，不用踢人。

### 在游戏里改（不碰文件）

**1. 断开接收**

```
/htg_connect reset
```

不断开的话，你画的路会被服务器的路网覆盖回去。

**2. 画路**

画的是**你当前所在维度**的路网。要给下界准备路网，先进下界。

**3. 上传**

```
/htg_connect upload
```

服务器会：

- 检查数据（解析失败 / 空路网 / 和该维度现有的一样 → 拒绝，并告诉你原因）
- 把该维度的旧文件备份成 `<文件名>.bak`
- 写入该维度的路网文件
- 推给所有在线玩家

全服看到「XXX 更新了服务器路网」；上传的不是主世界时，括号里会注明维度，比如「…（下界）」。
你自己另外看到「已成功上传路网，已推送给 N 个在线玩家」。

上传完你仍是「拒绝接收」状态：想接着改就继续画、再传一次；
想恢复正常就 `/htg_connect accept`。

**注意：由于协议层限制，单个维度的路网文件不得超过 8 MB**
(真的有人能画 8 MB的路网吗？)
**如有超出 8 MB的路网请联系作者**

## 房主开房（局域网）

什么都不用做。你画什么，房间里的人就同步什么，5 秒内到。

- 房主自己不弹窗（你就是服务端，没什么可接收的）
- 你自己所在的维度直接读内存，实时同步
- 其他维度读你存档里的路网文件，也就是上次离开那个维度时保存的那一份
- 你没去过的维度没有路网

## 指令

### `/htg_connect accept`

同意接收服务器路网，并立刻请求当前维度的路网。

### `/htg_connect reset`

清掉当前服务器的接收记录，下次进服重新问。

改服务器路网前先敲这个，断开接收。

> OP 等级 4

### `/htg_connect info`

打开「问道互联」面板，等同于按 `H`。

### `/htg_connect upload`

把当前维度的路网上传到服务器，替换服务端那份，推给在线玩家。

> OP 等级 4，只在独立服务端有效；单人/开房时提示「该命令无效」

## 配置

| 场景 | 路径 |
|---|---|
| 独立服务端 | `<服务端目录>\config\htg_connect-server.toml` |
| 房主开房 | `<客户端目录>\config\htg_connect-server.toml` |

```toml
# 玩家拒绝服务器路网时：true = 直接踢出服务器，false = 只弹一个提示
kickOnDecline = false
```

| 值 | 点「拒绝」之后 |
|---|---|
| `false` | 弹出提示「你可以使用 `/htg_connect accept` 以重新开始接收路网」，点确定就关掉，人还在服务器里。下次进服不再问。 |
| `true` | 直接被踢出服务器，提示「你拒绝接收服务器路网，无法在此服务器游玩」。再连回来会重新弹窗。 |

改完自动生效，不用重启。

## 常见问题

**进服没弹窗？**

1. 服务器还没有路网文件
2. 你之前对这个服务器点过「拒绝」→ `/htg_connect reset`
3. 你同意过、服务器也没改过 → 正常，不用再问

**路网没变？**

1. 服务端日志有没有「路网来源【文件】… 第 N 版」
2. 文件是不是放在 `config\htg_connect\` 下
3. `dimensions.json` 里有没有这个维度的条目
4. 文件里 `nodes` 是空的 → 会被当成"没有路网"

**下界 / 末地 / 模组维度有路网吗？**

看服务器有没有那个维度的文件。有就走进去自动接收，没有就什么都不发生，用你自己本地的。

给某个维度加路网（服主）：走进那个维度，画完 `/htg_connect upload`。

**我自己画的路过一会儿就没了？**

设计如此。服务器的路网是唯一权威，玩家改的会被覆盖。

想改服务器路网：`/htg_connect reset` → 画 → `/htg_connect upload`（需要 OP）。

**换了服务器端口，路网会不会没？**

不会。进服后重新下发，几秒内回来。接收记录会重置，可能要点一次「接收」。

**能只保留我自己画的路、不要服务器的吗？**

如果服务器允许拒绝的话，可以。注意同意后会覆盖自己的路网。
